# 03. Каталог тестовых сценариев

**Тип:** проектный набор для вымышленной игровой системы, без фактических прогонов.

Статусы не проставлены: нет тестового билда, API и согласованной спецификации. P0/P1/P2 — ориентировочные приоритеты.

Каждый кейс содержит условия, шаги и один проверяемый ожидаемый результат. Серверные проверки требуют логов/API/ledger.

**Всего:** 72; P0 — 9, P1 — 43, P2 — 20.
